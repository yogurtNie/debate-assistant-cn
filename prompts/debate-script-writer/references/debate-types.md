# 辩题类型

**来源**: 超辩学院 + 名家文章

---

## 价值辩

### 四大口诀
1. **价值无高低** - 不同价值观在不同情境下都可能合理
2. **价值无对错** - 价值观本身平等，只在特定前提下才有优劣
3. **价值有范围** - 任何价值观都有作用范围和前提
4. **价值有演绎** - 不同社会环境对价值观理解不同

### 实操要点
- 价值≠煽情，需基于事实和逻辑框架演绎
- 明确自己坚持的价值观体系，用严密逻辑展开
- 引起评委内心深处共鸣，而非用冰冷逻辑压倒人

### 价值辩子类型

#### 1. 比较型
**辩题特征**：A比B更重要/更好
**示例**："诚信比智慧更重要"、"先苦后甜比先甜后苦更幸福"
**论证重点**：建立判准，用判准衡量A和B

#### 2. 判断型（存在性/是非性）
**辩题特征**：某种状态能不能存在、某行为是不是某性质
**示例**："人能不能同时存在青春和对青春的感受"、"中立是美德还是狡猾"、"儒家思想能不能抵御西方歪风"
**论证重点**：
- 从**机制**论证：认知/逻辑上是否可能
- 从**定义**论证：概念边界是否允许
- 从**本质**论证：是否违背事物本质
**来源**：基于马萌《辩论赛的常识》对辩题分类的论述

#### 3. 哲学概念型
**辩题特征**：涉及时间、意识、存在等形而上命题（马萌："哲学范畴的、形而上的题目"）
**示例**："人性本善还是本恶"、"美是客观存在还是主观感受"、"时间能不能改变一切"
**论证方式**：机理论证 + 思想实验 + 概念分析为主，数据为辅或无数据
**来源**：马萌《辩论赛的常识》

## 政策辩：需根解损框架

### 四战场

#### 1. 需求性（Need）
现状有改变的需要：证明需求正当 + 不满足会带来严重弊端

#### 2. 根属性（Inherency）
造成弊端的原因：既有制度阻碍，必须透过积极措施才能改善

#### 3. 解决力（Solvency）
方案解决问题的能力：可行性 + 社会阻力 + 实际效果

#### 4. 损益比
利益与损害的比较：新危害是否可控，人力物力财力支出是否合适

### 前景理论（辅助理解）
公共决策倾向：谨小慎微、风险趋避、现实基础

## 事实辩

### 特点
- 辩题涉及客观事实认定、因果关系判断
- 示例："人性本善/本恶"、"时间能/不能改变一切"

### 要点
- 重点：机制拆解 + 数据支撑
- 判准：客观标准（可测量、可验证）
