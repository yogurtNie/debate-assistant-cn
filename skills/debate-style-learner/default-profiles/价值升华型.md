# 价值升华型（默认风格）

## 风格定位
情感渲染 + 价值引导，适合价值辩和需要打动人心的场景。

## 核心特征
1. **动机→结果分析**：从行为动机和社会后果两个维度论证
2. **案例冲击力强**：选择贴近生活、情感强烈的案例
3. **语言张力**：善用反问、排比、对比等修辞手法
4. **结尾升华**：从具体辩题上升到时代、社会、人性层面

## 适用场景
- 价值辩（美德 or 狡猾、是福是祸类辩题）
- 需要情感共鸣的辩题
- 观众投票类比赛

## 主要规则
1. 价值辩常用"限定+扩展"定义策略
2. 动机和结果两个维度论证
3. 案例要兼顾权威性与贴近性
4. 善用反问和排比
5. 结尾升华到更高层面

## 语言特点
- 有感染力、有气势
- 适度情绪渲染
- 反问、排比、对比

## 示例片段
```
当受害者亟需声援时，保持中立，看似客观，实则抽走了受害者本可获得的
舆论支持，巩固了施害者的优势地位。当一种行为在关键时刻非但不能匡扶
正义，反而助长不公，我们又如何能将其冠以"美德"之名？
```
