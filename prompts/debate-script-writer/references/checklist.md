# 写稿后自检清单

**用途**：完成框架稿或逐字稿后，按此清单自检，不通过先改

---

## 必检项（任一不通过必须修改）

### 1. 判准可操作
- [ ] 判准能让评委切实做出判断，不能"有和没有一个样"
- [ ] 可通过客观指标观察/测量，能真正区分双方
- [ ] 抽象价值已在具体情境中转化为可判断标准
- ❌ "促进人类幸福"、"让世界更美好"——大而不当
- ✅ "减少社会矛盾事件发生率"、"哪个能更快完成任务"

### 2. 数据有来源（硬规则）
- [ ] 出现的每条数据都有来源和年份
- [ ] 查不到来源的已标注【待核实】
- [ ] 无编造数据
- [ ] 数据密度符合辩题类型要求：
  - 政策辩/事实辩：每个分论点必须有数据
  - 价值辩：按需
  - 哲学概念类：可为零

### 3. 回扣判准
- [ ] 结尾明确回扣了判准
- [ ] 各分论点与判准的关系清晰

### 4. 匹配辩题类型
- [ ] 比较型价值辩：建立判准，用判准比较A和B
- [ ] 判断型价值辩：从机制/定义/本质三层论证
- [ ] 哲学概念型：以机理论证为主，避免数据堆砌
- [ ] 政策辩：需根解损四战场齐全
- [ ] 事实辩：机制拆解 + 数据支撑

---

## 建议项（不通过需说明理由）

### 5. 论点递进
- [ ] 主线采用时间/逻辑/因果递进之一
- [ ] 不是平铺直叙的罗列

### 6. 预判对方
- [ ] 列出对方可能的3-5个论点
- [ ] 每个都有我方回应预案

### 7. 语言表达
- [ ] 学术概念已解释
- [ ] 避免过度煽情（事实辩尤其注意）
- [ ] 哲学引用简洁（一句话，说明与判准关系）

### 8. 个人风格符合度
- [ ] 主线不超过3条
- [ ] 使用"一方面...另一方面"展开论证
- [ ] 框架稿包含独立攻防部分

---

## 自检流程

1. **先检必检项**：任一不通过立即修改
2. **再检建议项**：不通过需在稿件中说明理由
3. **记录问题**：每次自检不通过的项记入debate-tests/缺口报告

---

## 输出格式检查

### 框架稿
- [ ] 包含基本信息、核心框架、各环节要点、附加部分
- [ ] 预判对方至少3-5个

### 逐字稿
- [ ] .docx格式
- [ ] 首页写辩题/立场/赛制
- [ ] 按环节分节并标注预估时长
- [ ] 数据附来源标注
- [ ] 【待核实】高亮
- [ ] 页眉写辩题
