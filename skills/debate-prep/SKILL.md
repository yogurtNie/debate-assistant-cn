# debate-prep

## 职责
识别用户处于备赛的哪一阶段，引导至对应的专项 skill，并说明共用格式约定。

## 输入
用户描述的任务或问题，可能是：
- 想整理某场比赛
- 需要收集资料
- 要写稿子
- 不确定从哪开始

## 输出
- 判断所处阶段（复盘 / 资料收集 / 框架写作 / 多阶段混合）
- 推荐使用的 skill：
  - `debate-match-review`：整理历史比赛
  - `debate-material-pack`：建立资料包
  - `debate-script-writer`：写框架稿和逐字稿
- 说明共用格式：论点卡片字段、框架稿模板字段

## 读取的 references
- `references/论点卡片字段.md`：论点卡片标准格式
- `references/框架稿模板字段.md`：框架稿标准结构

## 工作流程
1. **检测 profile**：检查 `debate-profiles/` 是否有可用的个人风格配置
2. 分析用户输入，识别关键词（比赛视频、资料、数据、写稿等）
3. 给出阶段判断和推荐路径
4. **若无 profile**：提示"提供你以前的资料路径即可自动生成风格配置，或使用默认风格"，不做多轮询问
5. 如果是首次使用，简述三个专项 skill 的定位差异
6. 询问用户确认要使用哪个 skill，或由我直接调用
