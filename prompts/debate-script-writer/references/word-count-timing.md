# 字数与时长换算

**语速标准**: 340-360字/分钟（中文字符计）

---

## 一、换算表

### 立论/驳论/结辩

| 时长 | 目标字数 | 容忍范围(±8%) |
|------|---------|--------------|
| 2分30秒 | 875 | 805-945 |
| 3分钟 | 1050 | 966-1134 |
| 3分30秒 | 1225 | 1127-1323 |
| 4分钟 | 1400 | 1288-1512 |
| 4分30秒 | 1575 | 1449-1701 |
| 5分钟 | 1750 | 1610-1890 |

**公式**: 目标字数 = 时长(分钟) × 350

---

## 二、质询时长估算

按回合数估算，每回合25-35秒：

| 质询时长 | 估算回合数 | 总字数范围 |
|---------|-----------|-----------|
| 1分30秒 | 3-4回合 | 150-200字 |
| 2分钟 | 4-5回合 | 200-250字 |
| 3分钟 | 6-7回合 | 300-350字 |

**注意**: 质询不准备逐字稿，准备核心回应点即可。

---

## 三、自由辩论估算

语速通常快于立论（370-400字/分钟），按发言次数估算：
- 每次发言：15-30秒，90-200字
- 不准备完整逐字稿，准备论点卡片（每张50-100字）
- 按预估时长的120%准备卡片量

---

## 四、个人语速调整

### 提取语速（style-learner）
如果历史稿件有时长标注：
```
个人语速 = 总字数 ÷ 实际时长(分钟)
```

写入`preferences.md`:
```yaml
语速: 380字/分钟（快于标准）
3分钟目标字数: 1140字
```

### 使用顺序
1. 优先使用个人语速（profile中有记录）
2. 无profile时使用标准语速（350字/分钟）

---

## 五、字数自检

### 写稿后必做

1. 统计字数（去除标点和空格）
2. 计算偏差: `|实际字数 - 目标字数| ÷ 目标字数`
3. 偏差>8%时调整

### 报告格式（稿末注明）
```
字数统计:
- 目标: 3分钟, 1050字
- 实际: 1095字
- 预估时长: 3分8秒
- 偏差: +4.3% (通过)
```
