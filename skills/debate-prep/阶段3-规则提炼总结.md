## 提炼的可执行规则（精选 5 条）

### 规则 1：三段式开场白（必须遵守）
```
感谢主席，问候在场各位。
开宗明义，[核心概念定义]。
[判准/立场声明]。
```

### 规则 2：判准必须可操作（可验证）
❌ 坏的判准："促进人类幸福"（抽象）
✅ 好的判准："是否加速记住信息并且减缓遗忘"（可验证）

### 规则 3：主线不超过 3 条，有递进关系
三种常见模式：
- 时间递进：当下 → 长期 → 未来
- 逻辑递进：必要性 → 可行性 → 优越性
- 因果链：动机 → 过程 → 结果

### 规则 4：数据铁律
每条数据必须有：
1. 来源（机构名称）
2. 年份
3. 具体数字
查不到的标注【待核实】，禁止编造

### 规则 5：结尾必须回扣判准
标准结构：
```
综上（所述），[回顾核心战场] + [回扣判准] + [立场重申]。
因此，我方坚定认为，[辩题立场]。
```

## 风格特征总结

### 判准写法
**特点**：三句内说清，可操作
**示例**：
- "我方判断标准是，在互联网信息是否被加速记住信息并且减缓遗忘"
- "在茫然而不确定的一生中...是选择稳扎稳打按部就班，还是肆意长歌忽视外部风险"

### 论据密度
**特点**：高密度数据 + 权威来源
**统计**：
- 平均每个分论点：2-3 个数据支撑
- 数据来源类型：学术论文（60%）> 调查报告（30%）> 媒体报道（10%）
- 必带年份比例：80%

### 论点分层
**特点**：2-3 层主线，每层有内在联系
**常见结构**：
- 价值辩：动机层 + 结果层
- 事实辩：机制1 + 机制2 + 机制3
- 政策辩：必要性 + 可行性 + 副作用

### 语言风格
**特点**：
- 学术化但不晦涩（提出概念后立即解释）
- 数据密集但不枯燥（配合案例和比喻）
- 逻辑严密但有气势（反问、排比、对比）
