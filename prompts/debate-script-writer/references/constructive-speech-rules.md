## 立论构建流程

### 比较性辩题
**来源**：咨询群资料《比较性辩题的通俗打法》

**五步流程**：
1. **明确问题矛盾**：构造环境，凸显冲突
2. **寻找原因**：分析为什么会产生矛盾
3. **制定比较标准**：基于价值观，要具体可操作
4. **进行比较**：在同一标准下对比A和B（不是只论证A重要）
5. **得证结论**：价值观贯彻始终

**四大要点**：
- **A. 标准与价值观相关**：比较标准背后是价值观选择，不同标准有不同答案
- **B. 价值观因人而异**：不同主体（求职者/面试官/患者）有不同合理选择
- **C. 现状影响选择**：必须介绍辩题背景，让听众从你的视角看问题
- **D. 标准要可操作**：能切实做出判断，不能大而不当（如"让世界更美好"）

**比较方法**：
- 正常比较：在标准下直接对比A和B的表现
- 缺失性比较：对比"缺失A"和"缺失B"哪个后果更严重

### 政策性辩题
1. **明确需求性**：现状弊端+严重后果
2. **建立根属性**：找到具体阻碍（通常是制度）
3. **证明解决力**：可行性+社会阻力+实际效果
4. **计算损益比**：新危害是否可控

参见：`debate-knowledge/debate-types.md` 政策辩需根解损框架

## 立论表达原则

### 受众思维
参见：`expression-logic-rules.md` 表达规则
- 把评委当"小婴儿"：好理解就接受
- 不砸麻团：不要把纠结思想团成团砸向观众
- 通俗化表达：避免"开宗明义，概念先行"

### 立论结构
1. **介绍背景**：让听众从你的视角看问题
2. **明确标准**：具体、可量化、能真正比较
3. **展开论证**：从不同角度翻来覆去讲一句话的道理
4. **铺垫价值**：价值观贯彻始终

## 写稿约束

### 比较性辩题立论
1. **必须介绍辩题背景**（要点C）：让听众从你的视角看问题，感受价值观的重要性
2. **标准要具体可操作**（要点D）：能让评委真正判断A和B，不能"有和没有一个样"
3. **明确价值观选择**（要点A）：说明为什么你的标准合理
4. **真正进行比较**：不是只论证A重要，要在标准下对比A和B
5. **避免混淆根本性与重要性**：A是B的基础不等于A更重要，仍需价值判断

### 政策性辩题立论
1. 覆盖需根解损四个战场
2. 需求性：正当性+严重后果
3. 根属性：找到具体阻碍
4. 解决力：可行性+社会阻力+实际效果
5. 损益比：预判新危害并说明可控

### 表达要求
1. 通俗易懂，有画面感
2. 举平凡事例，让台下共鸣
3. 不要高高在上，理论高深
4. 从不同角度反复讲一句话的道理
