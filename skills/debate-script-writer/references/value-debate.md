# 价值辩立论规则

**来源**: 超辩学院（教材/课程 - 最高等级）

---

## 核心方法

### 选取主体与构建情景
- **切换主体**：不同角色有不同立场，切换主体找到新思路
- **构建情景**：在情景中塑造选择，通过选择获得认可

**案例**: "法海应不应该拆散许仙和白素贞"
- 主体1：文学角色视角 - 拆散才能构建价值冲突
- 主体2：佛教修行者视角 - 拆散与"三不能"冲突

---

### 观点=新资讯/新角度
- 只有叙述没有证明 = 没有观点
- 逻辑链每一环都要≥常识
- 三种论据：事例、数据、机理

---

## 立论体系四要求

1. **覆盖完整**：题目涵盖的内容尽力覆盖完整
2. **比较核心**：为什么你方比对方好
3. **不相互冲突**：态度统一，内部不冲突
4. **指导现实**：能更好地指导现实社会

---

## 新剑宗核心

### 论必须具有可证伪性
- 论必须引入新信息
- 若没有新信息论就能成立，则对方没有论证空间

### 优势原则 vs 心证原则
- **优势原则**：靠逻辑和事实占据优势
- **心证原则**：靠价值共鸣打动评委
- 两者相冲突，攻防结辩双强的辩手非常少见
