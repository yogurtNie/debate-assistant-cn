## 测试方法

1. **生成**：用当前规则生成框架稿（before/）
2. **检查**：按固定清单逐项检查，记录问题
3. **回查资料**：针对问题查找权威资料
4. **补强规则**：修改或新增规则
5. **回归验证**：重新生成（after/），对比改进
6. **裁决**：变好保留，变差回滚
