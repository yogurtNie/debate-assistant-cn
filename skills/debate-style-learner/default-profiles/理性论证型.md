# 理性论证型（默认风格）

## 风格定位
数据驱动 + 逻辑严密，适合事实辩和需要严谨论证的场景。

## 核心特征
1. **高数据密度**：每个论点至少 1-2 个数据支撑
2. **逻辑递进**：论点之间有明确的因果或递进关系
3. **学术化表达**：引用权威研究和学术概念
4. **结构完整**：开场→定义→立论→回扣，环环相扣

## 适用场景
- 事实辩（需要数据支撑的辩题）
- 政策辩（需要可行性论证的辩题）
- 评委偏好学术论证的比赛

## 主要规则
1. 判准必须可操作、可验证
2. 数据必须有来源和年份
3. 学术概念要解释
4. 论点不超过 3 个，每个深入论证
5. 结尾回扣判准

## 语言特点
- 平实、准确、严谨
- 避免过度情绪化
- 适度使用专业术语（但要解释）

## 示例片段
```
第一，互联网时代可以提供更多元化的信息形式，更有利于加速人们铭记信息。
哈尔滨工业大学论文研究显示，记忆网络存储的内容大多是输入图像的状态。
有研究表明，人脑的记忆，对于文字有效率占7%，而对于声音和图像的记忆率
却分别占到20%和47%...
```
