# 临场反驳规则

**来源**: 超辩学院（教材/课程 - 最高等级）

---

## 反驳步骤：定列比结

1. **定点**：明确反驳对象
2. **陈列**：复述双方观点
3. **比较**：分出高下优劣
4. **联结**：指出立场关联

---

## 反驳强度

- **质疑**：你是不是不对？（最弱）
- **击穿**：
  - 拆掉：你这样不对，因为...
  - 吃掉：你对了也没用，因为...（最强）

---

## 临场四大技巧

1. **制定策略**：根据场上形势调整反驳方向
2. **快速选点**：从对方立论中快速找到可攻击点
3. **翻译交锋**：学理糊脸时，选懂的说，接住然后翻译
4. **调整心态**：保持冷静，不被对方节奏带走
