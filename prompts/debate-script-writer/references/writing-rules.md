# 写稿规则

**来源**: 通用写作规范

---

## 基本结构

### 开场白
```
感谢主席，问候在场各位。
开宗明义，[核心概念定义]。
[判准/立场声明]。
```

### 结尾
```
综上，[回顾核心战场] + [回扣判准] + [立场重申]。
因此，我方坚定认为，[辩题立场]。
```

---

## 核心原则

### 1. 判准可操作
**核心标准**：判准能让评委切实做出判断，不能"有和没有一个样"

**判断方法**：
- 能通过客观指标观察/测量
- 能真正区分A和B（或正反方）
- 符合具体情境需求（抽象价值需在情境中转化为可判断标准）

**按辩题类型**：
- **比较型价值辩**：标准能真正比较A和B（如"社会信任体系稳定性"）
- **事实辩**：是否存在反例、是否可验证（如"是否存在不随时间改变的事物"）
- **判断型价值辩**：是/不是的判定依据（如"美德的定义标准"）
- **政策辩**：效果标准（是否实现目标）

**示例**：
- ❌ "促进人类幸福"、"让世界更美好"——大而不当
- ✅ "减少社会矛盾事件发生率"——可测量
- ✅ "是否存在不随时间改变的事物"——可验证（事实辩）
- ✅ "符合普遍道德原则+产生积极社会效果"——明确判定标准（判断型）

**来源**：咨询群资料《比较性辩题的通俗打法》+ 基于辩论理论推理（待验证）

### 2. 数据真实性（硬规则）
**铁律**: 出现的数据必须有来源和年份，查不到的标注【待核实】，禁止编造
**标准格式**: [机构] + [研究/报告] + [年份] + [具体数字] + [结论]

**数据密度按辩题类型**：
- 政策辩/事实辩：每个分论点必须有数据支撑
- 价值辩：按论证需要决定，可有可无
- 哲学/概念类辩题：以机理论证、思想实验、概念分析为主，数据可为零

### 3. 学术概念与哲学引用
**学术概念**：提出专业术语时立即解释：概念 → 提出者 → 一句话解释 → 应用到辩题

**哲学引用**（仅用于哲学/概念类辩题）：
- 只转述观点，一句话，不堆人名
- 说明与判准的关系，不为引用而引用
- 示例：✅ "只有失去的才能被真正拥有"（普鲁斯特）；❌ "普鲁斯特在《追忆似水年华》第三卷第142页提到..."

### 4. 论点逻辑递进
- 时间维度：当下 → 中期 → 长期
- 逻辑维度：必要性 → 可行性 → 优越性
- 因果维度：原因 → 过程 → 结果

### 5. 预判对方攻击
列出己方薄弱环节，预判对方3-5个论点，每个准备至少1个回应

## 时长控制

| 环节 | 时长 | 字数范围 |
|------|------|---------|
| 立论 | 4分钟 | 1000-1200字 |
| 质询/对辩 | 3分钟 | 600-800字 |
| 自由辩（单次） | 1分钟 | 200-250字 |
| 总结 | 4分钟 | 1000-1200字 |

**播报速度**: 约250字/分钟，建议控制在上限的80-90%

---

## 辩题类型要点

### 价值辩
重点：动机分析 + 结果评价
判准：价值标准（善恶、对错）

### 事实辩
重点：机制拆解 + 数据支撑
判准：客观标准（可测量、可验证）

### 政策辩
重点：必要性 + 可行性 + 利弊比较
判准：效果标准（是否实现目标）
