# debate-style-learner

## 职责
一次性自动从历史辩论资料中学习风格特征，生成个人 profile，无需人工逐项审阅或文件勾选。

## 输入
- 资料路径（可多个）：包含历史辩论稿的目录
- Profile 名称（可选）：默认取资料文件夹名

## 输出
直接生成完整的 profile 到 `debate-profiles/<名称>/`：
- `style-rules.md`：个人风格规则（每条注明依据的稿件文件名）
- `exemplars/`：3-5 篇范例（每篇附"好在哪"）
- `templates/`：提取的模板（可选）
- `preferences.md`：风格偏好说明
- `profile.json`：元数据
- `material-index.json`：素材索引（可选）

## 工作流程（全自动）

### 1. 盘点
- 读取目录结构与文件名
- 识别文件格式（docx/doc/pdf/txt）
- 抽样判断 PDF 类型（文字版 or 扫描版）
- 扫描版自动 OCR

### 2. 自动分类
依据：文件名线索、修改时间、篇幅、结构完整度
- **范例候选**：文件名含"定稿""终版""获奖"，结构完整
- **素材**：文件名含"资料""数据""论据"
- **存档**：明显的旧版本、重复文件

### 3. 自动质量筛选
优先选择：
- 结构完整（有开场、立论、结尾）
- 有终稿线索（文件名或修改时间较晚）
- 篇幅适中（800-1500 字）

### 4. 分批提炼（每批 ≤5 个文件）
- 转纯文本缓存到 `cache/`
- 之后只读缓存，不重复解析原文件
- 归纳：结构模板、判准写法、论点分层、语言风格、篇幅与时间分配
- 写成可执行规则

### 5. 自动区分个人风格与通用常识
- 在多篇稿子中稳定重复 → 个人风格
- 与内置通用规则一致 → 不写入
- 每条规则标注：
  - 依据的稿件文件名
  - 把握程度（高/中/低）
  - 样本支持度（X/Y 篇）

### 6. 自动选范例
选 3-5 篇最能代表风格的稿件：
- 结构完整
- 风格特征明显
- 各辩题类型覆盖
- 标注"好在哪"

### 7. 生成 material-index.json
索引所有资料文件：
- 文件路径、类型、分类
- 关键词、辩题、立场
- 数据来源列表

### 8. 直接定稿
写入 `debate-profiles/<名称>/`，无需人工确认每一步。

### 9. 最后输出简短汇报
- 处理了多少文件
- 学到的主要规则（列出 5-7 条核心规则）
- 选了哪些范例
- 把握不大的规则清单（供用户后续调整）

## 中途询问条件（仅这些情况）
- 路径无法读取
- 所有文件都无法解析
- 识别出多个明显不同的风格（需决定是否拆成多个 profile）

## 增量更新
再次指向同一路径或新文件时：
- 自动只处理新增或改动文件
- 合并到现有 profile
- 记录版本变化到 profile.json

## 冷启动
没有历史资料时，使用 `default-profiles/` 中的默认风格档。

## 约束
- 原始资料只读，不上传不外发
- 著作类只存笔记要点并注明出处
- 规则与通用硬规则（如数据必须有来源和年份）冲突时，硬规则优先并在汇报中提示

## 读取的 references
- `通用写作规则.md`（位于 debate-script-writer/references/）：用于区分个人风格与通用常识
- `default-profiles/`：冷启动时使用

## 缓存位置
- `debate-match-review/cache/`：共用缓存目录，存放转换后的纯文本

## 与其他 skill 的关系
- **被 debate-prep 调用**：用户提供资料路径时自动生成 profile
- **输出被其他 skills 使用**：debate-script-writer / debate-material-pack / debate-match-review 读取生成的 profile
