# 语言指纹提取

**目的**: 从历史稿件提取用户独特语言风格

---

## 一、提取维度

### 1. 常用句式
统计出现3次以上的句式模板，记录前5个

### 2. 开场与收束习惯
- 开场: 是否先定义？先点立场？先说判准？用设问/反问？
- 收束: 是否回扣判准？用排比？用呼吁？简洁直接？

### 3. 修辞偏好
统计每篇平均使用次数:
- 排比、对仗、比喻/类比、反问、设问
- 高频(>5次/篇) → 偏好；低频(<2次/篇) → 不偏好

### 4. 用词口吻
- 正式度: 正式(之所以、因此) / 中性(所以、如果) / 口语(那么、要是)
- 客观度: 客观(数据显示) / 主观(我方认为、显而易见)
- 学术度: 学术(机制、框架) / 通俗(方法、结构)

### 5. 句长分布
统计: 短句(≤10字) / 中句(11-20字) / 长句(>20字) 各占比

### 6. 口语化程度
评分1-5分:
1. 极正式: 无口语，全书面语
2. 偏正式: 少量口语连接词
3. 适度口语化: 混合
4. 偏口语化: 大量口语词汇
5. 极口语化: 接近日常对话

### 7. 典型过渡语
记录前5个最常用的过渡语（递进/转折/因果/举例/总结）

---

## 二、提取流程

1. 收集历史稿件（至少3篇立论稿）
2. 逐篇分析（标注句式、统计修辞、评估口吻）
3. 汇总特征（找共同特征，计算频率）
4. 提取代表性片段（3-5段，每段100-200字）

---

## 三、写入profile格式

在`preferences.md`添加"语言指纹"部分:

```markdown
## 语言指纹

### 常用句式（前5）
1. "首先我方要明确…"（开场）
2. "进一步来看…"（过渡）

### 开场与收束
- 开场: 先定义核心概念，再点明立场和判准
- 收束: 简洁回扣判准，不用排比

### 修辞偏好
- 排比: 低频(1-2次/篇)
- 比喻: 中频(3-4次/篇)

### 用词口吻
- 正式度: 中性偏正式
- 客观度: 客观为主

### 句长分布
短25% / 中55% / 长20%

### 口语化程度
3分（适度口语化），常用"其实"、"那么"

### 典型过渡语
"进一步来看"、"举例来说"、"数据显示"
```

在`exemplars/`创建`language-samples.md`，保留3-5段原文片段。

---

## 四、使用语言指纹

### 写稿时
1. 加载语言指纹
2. 模仿句式
3. 控制修辞
4. 调整口吻
5. 匹配句长分布

### 写稿后自检
对照`exemplars/language-samples.md`，列出不像的地方并修改。

---

## 五、Profile缺失时

回退默认风格:
- 适度口语化（评分3）
- 理性论证型
- 中性偏正式口吻
- 句式灵活（短25%/中55%/长20%）

说明: "当前使用默认风格，建议提供历史稿件生成个人profile"

---

## 六、语速提取

如果历史稿件有时长标注:
```
个人语速 = 总字数 ÷ 实际时长(分钟)
```

写入preferences.md:
```markdown
## 语速
- 个人语速: 380字/分钟
- 3分钟目标字数: 1140字
```

无时长标注则使用默认: 350字/分钟
