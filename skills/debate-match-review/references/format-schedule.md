# 赛制与环节切分

**来源**: 基于咨询群赛制资料

---

## 常见赛制时序

### 标准赛制（如国辩）

1. **立论**（各4分钟）
2. **攻辩**（各3分钟）
3. **攻辩小结**（各1分30秒）
4. **自由辩论**（各4分钟，每次≤30秒）
5. **总结陈词**（各4分钟）

### 海峡赛制

1. **立论**（各3分30秒）
2. **质询**（各2分30秒）- 时间紧，优先用防守型质询
3. **自由辩论**（各3分钟）
4. **总结**（各3分钟）

### 网辩赛制

1. **立论**（各3分钟，文字）
2. **对辩**（各5分钟，实时打字）
3. **自由辩**（各5分钟，实时打字）
4. **总结**（各3分钟，文字）

## 环节切分方法

### 视频录像切分

**按时间戳标记**：
- 00:00-04:00 正方一辩立论
- 04:00-08:00 反方一辩立论
- ...

**按关键节点标记**：
- [立论] 正方判准确立
- [质询] 反方连环套问
- [自由辩] 核心战场交锋
- [结辩] 胜负手出现

### 文字稿切分

按环节分段：
```
## 正方一辩立论
[内容]

## 反方一辩立论
[内容]
```

---

## 各环节复盘要点

### 立论
判准是否清晰？逻辑链是否完整？是否预判对方攻击？

### 质询/攻辩
问题设计是否成功？答辩是否拆解了对方问题？

### 自由辩
战场选择是否正确？是否陷入纠缠？

### 结辩
是否回应了对方最有力的点？反驳优先级是否正确？
